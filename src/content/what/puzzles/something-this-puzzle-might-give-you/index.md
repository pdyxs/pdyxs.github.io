This is a hybrid between a sudoku puzzle and a word puzzle, which is aiming to integrate both skills.

## Rules

**Wordoku:** Enter the letters from A-I into the grid, so that each letter appears once in each row, column and box.

**Words:** Grey lines spell out English words, and all words begin at a circle. If a grey line branches, each branch represents a different word with a common beginning.

**Repeat letters:** All letters which have appeared earlier in the same word are marked with a square.

The puzzle title is a clue for the longest word.
