Yesterday, I started playing around with genetic sequences, to see if i can visualise them in an interesting way. So far, I've been playing with the ebola virus (it's by far the simplest - it only has 7 genes!). These are the first 3 attempts.

The first two attempts are different colourations of the same basic idea: just take the nucleotides and render them as different coloured pixels in a square. For the third image, I've taken into account the structure: each horizontal line is a gene, and the thicker parts are the coding regions (the bits that directly relate to the protein being made). Next, I want to start representing the amino acids that are being created in the coding regions, and dealing with the fact that one of the genes has three variations
