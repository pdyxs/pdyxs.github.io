Welcome to my website!

I've built this with a few things in mind:
1. I want a place where everything I've made can live. In the past I've published in a lot of different places, and a lot of those places have been lost over time. So from here on in, this is my contents' home base.
2. I want a place where I can easily publish experiments. I'm not sure what shape my future projects are going to take, but I've set this up to allow for as much flexibility as possible.
3. To try out new approaches to handling streams of content. It's becoming clearer and clearer that existing algorithmic feeds aren't great for us, but what alternatives do we have?

I'll be exploring different parts of this in different posts, these should appear below!
